# Agent Provider Contract

Contextula keeps the workspace boundary and durable writes. Agent providers supply reasoning.

A provider receives a prepared research packet and returns structured findings. It does not receive raw access to the whole data home or arbitrary sibling workspaces.

## Research packet

Generated by:

```bash
contextula agent packet <workspace-id>
```

Shape:

```json
{
  "version": 1,
  "kind": "contextula.research.packet",
  "workspace": {
    "id": "cus_...",
    "name": "Example Plumbing",
    "type": "customer"
  },
  "profile": {},
  "claims": [],
  "artifacts": {
    "homepage": "# Homepage Snapshot..."
  },
  "policy": {
    "workspaceOnly": true,
    "noExternalContact": true,
    "readOnlyWeb": true
  },
  "objective": "Build a bounded first-contact modernization research pass."
}
```

## Provider response

A provider returns JSON:

```json
{
  "observations": [
    {
      "text": "The site appears to emphasize urgent response.",
      "source": "research/extracted/homepage.md",
      "confidence": 0.72
    }
  ],
  "claims": [
    {
      "text": "Fast response is likely an important positioning angle.",
      "source": "research/extracted/homepage.md",
      "confidence": 0.68
    }
  ],
  "recommendedNextSteps": [
    {
      "title": "Review emergency CTA prominence",
      "rationale": "Urgency messaging should map to an obvious action."
    }
  ],
  "openQuestions": [
    "Does the business prefer phone calls over forms?"
  ]
}
```

Contextula validates provider responses before writing durable claims/events:

- top-level response must be an object
- `observations`, `claims`, `recommendedNextSteps`, and `openQuestions` must be arrays when present
- observation/claim `text` must be a non-empty string
- recommended next-step `title` and `rationale` must be non-empty strings
- confidence values are clamped to `0.0..1.0`; missing/invalid values default to `0.5`

Fixtures:

- `docs/fixtures/provider-response-good.json`
- `docs/fixtures/provider-response-bad-missing-text.json`

Quick local check:

```bash
contextula agent research <workspace-id> --provider json --response docs/fixtures/provider-response-good.json
```

## Safety rules

- Providers may recommend, summarize, and draft findings.
- Contextula performs all durable writes.
- External contact, deployment, pricing, billing, or customer-facing commitments require approval gates.
- Providers should cite workspace artifacts or mark findings as tentative.

## Current providers

- `static` — deterministic local provider for tests and smoke flows.
- `json` — reads a provider response JSON file from `--response <path>`. Useful for OpenClaw/manual handoff until a direct adapter exists.

Future providers can wrap OpenClaw, local inference, hosted models, or a task-specific agent runtime as long as they honor this contract.
