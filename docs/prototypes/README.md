# Contextula Prototypes

Standalone design prototypes for fast iteration without creating or regenerating customer workspaces.

- `contextula-outreach-invitation.html` — high-polish prospect/onboarding surface. This is the design lab for the first customer touchpoint before porting the style back into generated review packages.
- `assets/` — generated visual assets for the prototype, including the fanged-C mark, proposal castle hero, preview browser mockup, candle closing image, gothic hero background, operator console mockup, and full-page outreach artboard reference.
- `outreach-art-direction.md` — durable art-direction contract for atmosphere, composition, emotional tone, visual storytelling, brand/copy requirements, and what the outreach page must make a prospect feel.
