# Contextula Prototypes

Standalone design prototypes for fast iteration without creating or regenerating customer workspaces.

- `contextula-outreach-invitation.html` — high-polish prospect/onboarding surface. This is the design lab for the first customer touchpoint before porting the style back into generated review packages.
- `assets/` — generated visual assets for the prototype, including the fanged-C mark, gothic hero background, and operator console mockup.
